# Le Labo, outil de suivi-évaluation du PASEA

Interface de l'outil de suivi des activités de la Cellule Suivi-Évaluation de l'UC-PASEA (crédit IDA 7562-CI).

- `index.html` : l'interface, publiée par GitHub Pages.
- Les données restent dans les classeurs Google Sheets du compte de l'équipe. Elles passent par le serveur Apps Script, après connexion par identifiant et code personnel.

Ce dépôt ne contient aucune donnée du projet. Ne pas y déposer `demo-data.js`.

Développé par M.J, Cellule Suivi-Évaluation, UC-PASEA, 2026.
